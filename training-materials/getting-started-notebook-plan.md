# Getting-started notebook plan

The companion DNAnexus `[DX]` notebook will provide hands-on practice that mirrors the tutorial:

1. Check the R kernel.
2. Run a simple R command.
3. Read synthetic data from `/mnt/project`.
4. Display a table.
5. Create a plot.
6. Save the notebook.
7. Restart JupyterLab and confirm the notebook and outputs persist.
8. Optionally test the advanced R output helper.
